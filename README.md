# Parking-Gate-System-with-Arduino
In this repository i will make tutorial how to make a simple parking gate system with arduino and other components such as servo motor and ultrasonic sensors

Installation
Connect the Ultrasonic Sensor to the Arduino (VCC to 5V, GND to GND, TRIG to pin ~6, and ECHO to pin 7).
Connect the Servo Motor to the Arduino (Control pin to pin ~9).
Upload the Parking_servoMotor.ino code in the Arduino IDE.
