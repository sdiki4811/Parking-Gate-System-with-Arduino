# Parking Gate System with Arduino
In this repository I will create a tutorial on how to make a simple parking gate system with Arduino and other components such as servo motors and ultrasonic sensors.

## Required Components
To create a parking gate system, you will need the following components:
1. 2. Arduino Uno R3
2. SG90 Servo Motor
3. HC-SR04 Ultrasonic Sensor
4. Jumper Cable
5. Power Supply (5v Cable to Laptop)
Below is a schematic diagram illustrating how to connect all components:
https://github.com/RavalentMarshal/Parking-Gate-System-with-Arduino/blob/main/Parking%20Gate%20System%20%231.png

## Manufacturing Steps 
1. Arduino Preparation
- Connect Arduino Uno to the computer and open the Arduino IDE application.
2. Component Connection
- Connect the servo motor to the PWM pin on the Arduino
- Attach the ultrasonic sensor with the VCC cable to 5V, GND to GND, TRIG Pin to ~6, and ECHO Pin to 7 Arduino.
3. Upload Program
Upload the code that has been created to Arduino
